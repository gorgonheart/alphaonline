# 共享计算提速：GC、MODEL日期与Ubuntu验收

本轮遵循已确认的[实施计划](superpowers/plans/2026-11-04-speed-followup.md)，在当前工作区原生实施并保留已有未提交修改。范围是初始化、4050续算、修订回放及交易前计算；测试服务器为43.173.122.28。没有修改alpha、startup、账户策略数学、S3或订单公式，没有真实下单。**离线验收、测试部署、传统45m与跨日5m真实dryrun均已完成。**

## 最终保留的改动

| 文件 | 改动 | 保持的行为 |
|---|---|---|
| `core/utils/factor_data.py` | 新增局部`temporary_gc`：暂时关闭自动GC，结束时仅收集第0代，然后恢复进入前开关 | 非嵌套、串行协调器使用；成功及异常均恢复；不全局禁用GC |
| `core/backtest.py` | 共享计算价格报告的读、写、释放使用上述局部GC | 原Parquet字段、行窗口、最终删除顺序不变 |
| `tools/initialization_pipeline.py` | 映射读取与pandas转换使用上述局部GC，保留单独GC计时 | 原六列及过滤条件、深拷贝和Windows mmap所有权保障不变 |
| `positions/ModelRobust40Strategy.py` | `coin_features`直接使用原生NumPy datetime和pandas DatetimeTZ日期列 | 字符串、ArrowDtype等仍走原`pd.to_datetime`；缺上市日期的回退、NaT及公式不变 |

仅两个core文件，无startup改动。此处“原生日期”指转换为pandas后的NumPy/DatetimeTZ类型，不包括pandas ArrowDtype扩展类型。不能简单用`is_datetime64_any_dtype`判断，否则Arrow时间列可能改变返回dtype，含NaT时甚至溢出。

`temporary_gc`只覆盖新建转换对象的短生命周期，避免遍历已换出的旧堆。它不是通用嵌套GC管理器；内层收集可能把外层对象升代，因此只允许现有两个串行、非嵌套调用点。异常traceback持有的对象仍是可达对象，与此前全代GC一样不能强制回收。没有改全局阈值、`gc.freeze()`或进程回收策略。

## 实测与取舍

### GC：保留

同一完整15m输入，旧初始化映射阶段全代GC13.127秒，新第0代GC0.0023秒；映射读取/转换/释放合计20.662→8.110秒，约少12.55秒。没有把读盘时间计作GC收益，也没有删除深拷贝。

Windows真实4,616,442行映射验证：删除所属临时IPC后，返回pandas表仍可访问；调用前GC关闭时，退出后仍关闭；第0代GC0.000298秒，读取、转换、删除完整探针1.505秒。对应证据为`.superpowers/sdd/2026-11-04-speed-followup/full-mapping.log`。

### 选币每组GC：撤回

### 聚合并行、备用v2：尚不启用

14组实际选币输入，原聚合1/2/2/1任务耗时39.722/25.273/25.153/39.592秒，约有14.5秒潜力。但该试验在任务内创建和释放聚合矩阵，只返回小摘要，没有同时进行14组后续模拟，不能当作“完整聚合+模拟减半”证据。

## 剖析后剩余热点

### MODEL

完整候选的cProfile中，calculate160.332秒：模拟/恢复点72.209秒，其中Numba首次编译60.448秒、模拟数值内核约10.773秒；observations50.956秒，其中coin_features38.213秒、重复日期解析16.951秒；父组合16.259秒；季度预测2.469秒。嵌套累计时间不能相加。

因此本轮只消除已有原生日期列的重复解析。不能把60秒冷编译算作每小时成本；暂不为季度训练引入缓存协议，也不并行改写模拟内核。

最终原生日期优化的无cProfile ABBA测试：同一69币种，旧2.5298/2.6188秒，新1.0123/1.0410秒，均值约减少60.1%。这是包括函数临时对象创建/销毁的特征计算样本，不包含先前公共raw读取及其他初始化阶段，不能称整轮减少60%。756个完整历史币种特征精确一致。

### 时序因子

49个均匀抽样币种、597,261行，完整单进程剖析32.448秒，含读、合并、计算、转Polars，不含整批跨进程传输/IPC写块。主要累计耗时：滚动9.683秒；两类外部数据合并4.959秒（市值加载4.030秒）；BiasV1 3.581秒；ZfMeanQ 3.137秒；Cci异常隔离3.037秒；pandas→Polars1.577秒。累计时间有包含关系，不能直接相加或外推全市场节省秒数。

下一阶段优先候选是市值逐行map、BiasV1逐行窗口，以及个别因子重复日期解析。必须保留已有删行重索引、参数顺序、NaN/并列排名行为，逐项独立oracle和全成本A/B。当前证据不支持为了1.58秒转换优先重写整个数据表示。
