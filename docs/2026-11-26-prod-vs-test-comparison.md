## 6. 背景：今日 `10:25–14:25` 为何缺三轮（口径外）

`13-test-gap-detail.txt` 原始行：

```text
MODEL历史修订 2026-11-25 11:25:00；共同恢复至 2026-11-25 10:25:00，子策略/S3/MODEL重新计算
🌀 启动时间：2026-11-26 10:25:00
++++++++++++++++++++++ 🚀 [25m-eart1106] 开始 2026-11-26 10:26:44 +++++++++++++++++++++++
```

`10:25` 轮检测到 `11-25 11:25` 的历史数据修订，回退到 `11-25 10:25` 全量重算，从 `10:26:44` 占住消费进程直到 `14:2x`，`11:25/12:25/13:25` 三轮未产出（`select_coin` 今日只有 `_10,_14,_15,_16,_17,_18`）。`01` 文件中该段只有 `revision_detected / restored`，没有 `end` 行。这与新版本代码无关，是历史数据修订触发的重算；但**它把 4 小时的计算窗口吃掉了**，若在正式机发生同样规模的修订，会直接影响实盘轮次，建议单独评估"修订回填的并发与限流"。

## 7. 结论

1. **17:00 后新版本收益明确**：同切点、同 `1299` 帧，`total_s` `94.20 vs 141.29`（**−33.3%**）与 `88.20 vs 129.24`（**−31.8%**）；主要来自 `prepare_s`（−20.2 / −22.6 s）与 `input_read_s`（−5.3 / −7.5 s），计算段只快 `3.0 / 4.8 s`。
2. **上游就绪提前**：`19:25` 批次 `.ready` 测试机 `spot 44.97 s / swap 61.42 s` vs 正式机 `85.94 / 115.71 s`，提前 **41 / 54 s**；barrier `0.40 / 2.20 s`、`missed=0`。
3. **方向一致**：`535` 币里仅 `KERNELUSDT`（两切点）与 `MOVEUSDT`（`_18`）方向不同，均在 `#3.线上实盘多头`，属实盘持仓依赖；策略信号本身未见变化。
4. **目标数量存在按策略分化的系统性差异**（整体 −22%，`VolumeMaxBias` 0.50、`线上实盘多头` 0.41–0.77，而 `大学生` / `选0.2` / `截面因子` ≈1.000）。这是本次最需要跟进的数据一致性项，根因待比对两机子策略资金配置。
5. **净值一致**：`17:25` `17076.39 vs 17079.31`、`18:25` `17221.53 vs 17205.09`，差在 ±17 美元内；`现货净值` 口径两机不同（`7119` vs `513`），不可直接横向比较。
6. **待确认**：① 上述数量比例分化的配置根因；② `KERNELUSDT` / `MOVEUSDT` 的实盘持仓差异是否符合预期；③ `10:25–14:25` 修订重算的限流策略；④ 换仓明细行数 3 倍差异的成因。
