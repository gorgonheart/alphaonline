# 四币分歧归因：2026-11-04 19:25 HK

本报告只解释已有共同轮次的 GUSDT、LSKUSDT、RAYSOLUSDT、ONUSDT 分歧，不代表完整上线验收通过。对比方向均为测试减生产；百分比差使用“占账户权益的百分点”。没有修改业务、重启服务、下单、发通知或恢复采集器。

## 1. 结论及贡献拆分

这四币约占该轮最终合约权重绝对差总和的96.46%。主要分歧来自输入数值穿越筛选门槛，保留下来的历史选择继续参与当前持仓。四币 S5 MODEL delta 都是0；父仓管权重另有较小贡献，不能把全部差异归到 MODEL 训练。

|币种|最终权重差，百分点|子策略持仓比例差贡献|父仓管权重差贡献|
|---|---:|---:|---:|
|GUSDT|+0.2726797830|+0.2700838095|+0.0025959735|
|LSKUSDT|-0.1918025724|-0.1928031937|+0.0010006213|
|RAYSOLUSDT|-0.0465435595|-0.0462532307|-0.0002903288|
|ONUSDT|+0.0348936074|+0.0349605036|-0.0000668962|

拆分恒等式为 `(测试子策略比例−生产子策略比例)×生产父权重 + 测试子策略比例×(测试父权重−生产父权重)`，逐子策略相加。父权重取实际仓位比例CSV，包括再择时，不把原始parent直接当有效权重。完整数字见 four-coins-attribution.json。

## 2. G、LSK：GTC改变候选数量和等权分母

|分支|生产候选→选中数（后滤之前）|测试候选→选中数（后滤之前）|实际影响|

反事实校验：保留生产截面其他数值，只替换GTC的Bias360为测试值，两个分支均还原测试选币集合及分母。两端两个分支的实际历史记录共4组，币种及权重精确一致。

## 5. G的小额Funding剩余差异

发生时刻：11月4日04:25 HK（11月3日20:25 UTC），Funding938+ILLQ96分支。主minmax归因之外，G还有约+0.0001593383个百分点的子策略比例贡献。

- 生产LPT百分位338/519=0.651252408477842，不通过。

尚未关闭的边界：

1. **上游原始来源为何不同**：冻结Arrow保留的是合并结果，未包含这些历史时刻DataAPI原始记录、Binance原始记录及逐币覆盖顺序。后补当前行情不能恢复当时输入版本。若继续追生产者，仅需BIRB 11-03 16:25 UTC、GTC上述4个close时刻、RAYSOL上述3笔funding_fee的两来源值、采集/修订时间和最终采用来源；不需要市场全量文件。本轮没有添加生产者采集逻辑。
2. **LPT/MYX上游ILLQ预计算一致性**：只需要这两币对应20:25 UTC决策的OHLC/quote_volume历史及当时预计算实现/参数。数值依赖至少576小时；若验收浮点逐位一致，应复用已有冻结完整单币历史，不能截短后假定滚动计算数值状态完全一致。现有发布值与排名已足够解释这项很小的分配变化。
3. **父仓管历史状态来源**：贡献已精确拆出，尚未逐季度追溯既有训练/子策略净值历史差异。复用已完成实际旧/新MODEL共同输入共同起点12/12精确证据，不能将它扩展为完整上游/S3/持久化都通过。

这份报告关闭的是四币主要分歧的解释；生产状态衔接、完整同输入上游对拍等既定上线验收缺口仍单独保留，不自动实盘放行。
