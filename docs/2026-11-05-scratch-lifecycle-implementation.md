# 初始化与回放工作区生命周期落地

本轮按已确认的磁盘审计方案本地实现，未提交、未部署生产业务代码、未重启或清理新的生产数据。正式机基准源码上传被自动审批拒绝，未绕过；Linux微基准改在43.173.122.28的test/lifecycle_probe_20261105独立目录执行，仅复制助手/基准，无运行入口替换。其他任务的未提交文档保留。

## 实现范围

- tools/robust40/lifecycle.py：路径受限的非致命清理、按账户残留回收、活动进程归属判断、平面日志限量；真实删除输出SCRATCH_CLEANUP与elapsed_s。
- cli/server_robust40.py：初始化开始在现有账户锁内清理旧任务；try/finally覆盖冻结/计算/安装失败，退出时释放自有工作区。prepare显式告知恢复函数已持账户锁，避免重入。
- server.py：原成功清理接口转调用非致命删除，保留原精确root/account/stamp约束，不使成功安装因清理错误变为失败。
- handoff.py：回放采用data/model_replay/<完整snapshot名称>/work-*，消除相似账户名称前缀冲突；copy/restore异常、未提交失败、提交后工作空壳均回收。原complete=True后订单异常不回退计算状态。
- initialization_config.py：DIAGNOSTIC_LOG_COUNT=24。

没有core/startup/账户/因子/S3数学/状态协议变化。.previous仍单份保留；.replay-previous必须先按事务恢复，不能交给普通垃圾清理。

## 运行规则

1. 自动初始化失败不再永久保留冻结行情和部分snapshot；外层账户stamp.log保留，最多24份且保护当前打开日志。正常成功原来就删工作区，本轮不重复扫描进程。
2. 被杀进程的旧初始化目录，下次该账户初始化时回收。只枚举该账户直属stamp目录，不扫描市场文件大小。复用现有初始化/账户锁；候选存在时才检查Python worker的ROBUST40_SERVER_WORKER归属。
3. Linux先按UID排除无关用户Python，不读取其环境。若相关归属无法确认则保守保留；不通过年龄或PID文件猜测安全。
4. 回放残留只扫描新账户子目录，且只在存在候选时做进程检查。活跃交易子worker继承项目root，存在则暂缓回收。中断事务有backup时也在切换之前检查，活跃或不可读时抛BlockingIOError，阻止后续交易继续。
5. 损坏中断目录不再保留整包，只保存每账户固定last-failure/warmup.pkl样本（最多64KiB），然后释放大文件。诊断样本不是新manifest/账本。
6. 删除失败、文件仍被Windows映射、输出管道关闭等只记录并留待重试，不覆盖原计算异常。没有新增定时器、每轮全盘du、哈希或容量注册表。
7. 显式手工research工作区仍不由自动初始化精确路径清理；旧版model_replay平铺目录不以模糊前缀自动删除，需一次性人工核对清理。当前正式机上一轮审计未发现大回放遗留。

## 性能实测

Ubuntu测试机，助手独立加载，不运行策略：无工作区检查100次中位0.070ms/max0.140ms；空账户回放目录100次中位0.025ms/max0.063ms；仅残留路径需要的进程检查5次中位19.45ms/max45.37ms。创建1000个1KiB文件的硬链接约25.3–25.6ms，删除约7.91–8.09ms，合计33.2–33.6ms。

Windows：无工作区约0.997ms、空回放约0.370ms；进程检查中位51.7ms，冷调用最大1161ms，因此绝不放到正常成功路径。1000硬链接删除约0.78–1.72秒，含创建1.56–3.00秒。不同机器文件系统不能直接推算真实大目录释放时间；保留逐次删除elapsed_s便于观察。基准统计包含创建，不以纯rmtree内核冒充端到端。

正常无失败轮没有全进程扫描。已有成功初始化删除成本原本就存在；新增失败清理只在退出/安全重试处发生。回放没有残留时至多账户目录存在检查及空目录枚举。

## TDD及复核

逐步RED/GREEN覆盖硬链接不影响公共源、路径/symlink边界、当前任务和其他账户保留、活跃初始化/回放worker阻止删除、清理失败与warnings-as-errors不覆盖错误、损坏备份只留小元数据、正常成功零进程扫描、初始化成功/失败finally、无新修订回收、已有锁重用、提交前恢复与提交后订单错误不回退。

独立复核指出并修复相似账户目录匹配、跨UID读取导致永远不清理、回放孤儿worker、嵌套锁和有backup的恢复安全问题。最终相关106通过、2跳过（Windows符号链接权限、POSIX UID限定），51.76秒。测试机另用真实存活子进程和foreign-UID模拟验证归属判断通过。清理不改数值内核，相关共同恢复/增量状态回归已运行；本轮没有重新执行全市场因子计算或声称真实成交通过。
